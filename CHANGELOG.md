# Changelog

All notable changes to Digital Sentinel are documented here.

## Unreleased
### Added
- World Monitor–style dashboard layout with header, map, panels, and ticker.
- Live RSS news aggregation with in-app browser viewing.
- World Brief panel driven by live headlines.
- Live map overlays for intel hotspots, conflict zones, and military bases (public sources).
- Pentagon Pizza Index (PizzINT) DEFCON indicator and detail panel.
- Launch screen storyboard and explicit interface orientation support.

### Changed
- App renamed to Digital Sentinel and bundle identifier updated.
- Map rendering updated to overlay live points and show tap details.
- Bottom feed panel now uses a fixed safe-area inset on phone.

### Fixed
- Info.plist bundle identifier and launch config issues.
- Build issues related to string literals and missing UIKit import.
